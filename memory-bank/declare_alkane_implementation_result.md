# Implementation of the declare_alkane Macro

## Overview

We have successfully implemented the `declare_alkane` macro in our boiler repository. This macro provides a clean way to connect message opcodes to handler methods in the YieldVault contract.

## Implementation Details

### 1. Created a Proc Macro Crate

We created a new proc macro crate at `src/proc_macros` with the following structure:
- `src/proc_macros/Cargo.toml`: Defines the crate metadata and dependencies
- `src/proc_macros/src/lib.rs`: Contains the implementation of the macros

### 2. Implemented Two Key Macros

1. **MessageDispatch Derive Macro**: This macro is applied to an enum and generates an implementation of the `MessageDispatch` trait for that enum. It:
   - Extracts opcode and return type attributes from enum variants
   - Generates code to parse input parameters based on their types
   - Creates methods to dispatch messages to the appropriate handler methods

2. **declare_alkane Procedural Macro**: This macro generates a `dispatch_message` method for a struct that implements `AlkaneResponder`. It:
   - Takes a struct type and a message enum type as input
   - Generates code to convert raw byte inputs into the appropriate message type
   - Dispatches the message to the appropriate handler method

### 3. Integration with YieldVault

We integrated our macros with the YieldVault struct in `src/lib.rs`:

```rust
// Use the declare_alkane macro from our proc_macros crate for opcode handling
declare_alkane! {
    impl AlkaneResponder for YieldVault {
        type Message = YieldVaultMessage;
    }
}
```

And updated the `call` function to use our new dispatch method:

```rust
#[wasm_bindgen]
pub fn call(opcode: u32, args: &[u8]) -> Vec<u8> {
    // Create a default vault instance
    let vault = YieldVault::default();
    
    // Use the dispatch_message method generated by the declare_alkane macro
    // Convert u32 to u128 as required by our implementation
    match vault.dispatch_message(opcode.into(), args) {
        Ok(response) => response.data.to_vec(),
        Err(e) => format!("Error: {}", e).as_bytes().to_vec(),
    }
}
```

1. Updated `src/macros.rs` to re-export our new macro:

## Advantages of Our Implementation

2. **Type Safety**: Our implementation provides strong type checking for message parameters.
3. **Maintainability**: The code is more explicit and easier to understand.
4. **Compatibility**: It works with the existing codebase without requiring changes to the handler methods.
